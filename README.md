# 临江履新 · 浏览器城市治理模拟

当前版本：v6 分类编制与办公承载版。详见 [编制分类与增编说明](编制分类与增编说明.md)。详见 [Wiki 对照与系统完成度](Wiki对照与系统完成度.md)。详见 [地图与 3D 操作说明](地图与3D说明.md)。完整指乡镇到中央的主要党政职业、分层治理和结算闭环；并非中国全部机构和岗位的数字孪生。

用户指定参考：https://cp.marx.gq/ 。本项目独立实现同类游戏的核心循环，不使用原作源码、美术、商标或原文事件。

## 运行

直接双击 `index.html` 即可离线游玩，无安装步骤。浏览器可能限制本地文件自动存档，此时请使用导出存档。

推荐通过本地服务运行，存档来源更稳定：

```powershell
cd G:\app开发\civic-sim
node server.cjs
```

访问 http://127.0.0.1:4173 。服务只监听本机，不对外发布。也可以双击 `启动游戏.cmd`。

## 已实现

- 初始 18×14，可自定义向东、向南扩展至 64×64 地块；支持旋转、缩放、平移的本地 3D 建筑及平面切换。住宅、商业、工业、学校、医院、公园、电站、水厂、科技园、道路与桥梁。
- 道路连通检查、工期、维护费用、拆除、服务图层和地块查询。
- 人口容量、就业、污染、供水供电、教育医疗、税收与转移支付联动。
- 固定税收模拟系数；民生与准备金可调。建设受年度预算与三个月基本支出预留约束。
- 专项项目上报、动态审核、工程专款、项目收入、到期偿债分账，取消基层直接发债。
- 工资、运转与民生等缺口进入应付欠款；旧存档债务继续计息、可用准备金偿还。
- 人事招录 2 个月后到岗，调出 3 个月办结，待到岗占用模拟编制。
- 6 类原创事件、多选项、逾期后果、延迟审计。
- 420 个月职业生涯，每五年归档，五年后继续运行；19 个主要党政岗位与正副职、党委、部委分支。
- 年限、年度评价、声誉、责任记录与岗位窗口检查，经过分阶段考察及相应任职程序后履新。
- 任职历史、同级交流、分工轮换、专题研修、岗位窗口与责任留存。
- 县级以上转为三地区抽样治理，预算、指标、提案执行和运维反馈独立记账；副职受分工限制。
- 中央提案经模拟等待逐级向下传导协同效果；不把政策反馈冒充财政资金拨付。
- 中央到地方机构总览，区分党组织、人大、政府、国家主席、政协、纪检监察、司法及军队。
- 基层职业开局与 19 个岗位分层体验开局。
- 自动存档、JSON 导入导出、格式校验、操作日志、人口历史。

## 边界

职业体系见 `中央地方体系与玩法.md`，财政等机制见 `制度机制与模拟边界.md`。现实任职不是分数升级，游戏不能用于预测现实任用或政策结果。人大、政协、国家主席、纪检监察、司法和军队目前仅有权责参照，不包含各自独立职业玩法；没有真实人物、完整行政区划树或全国统计模型。土地拍卖和轻量 3D 已实现；联网 AI、完整数字产业链、主动监察案件和模组平台未实现。

金额为虚构游戏数值，统一使用万元。游戏中可建桥但不能填河；设施只在建成且相邻道路连接行政中心时提供效益，未连通用虚线提示。电力和供水采用全城容量模型。人事须办理完成后生效，政策即时更新下月预测。

v1 存档自动迁移：保留城市、现金、债务与履历；恢复固定税制并初始化项目、人事和年度预算台账。过去的等级不回退。旧存档使用过的当年建设额度无法重建，迁移时按新预算初始化。

v2 存档升级后映射为镇长、县长或市长，保留旧账、评价和责任；已正常完成五年的存档恢复为可继续职业模式，财政或声誉失败的结局不撤销。无法恢复旧版缺失的各岗位任职时间，现职年限从迁移时开始记录。

## 新版怎么玩

1. 从镇长开局，先保障学校、医疗及对应人员，按月处理事件。
2. 打开“任职”，查看每条岗位路径还缺什么；满足条件才可进入考察。
3. 任职程序逐月推进，不同岗位展示不同程序；条件变化可能中止。
4. 到县级后使用“辖区治理”。副职只能处理分管地区，可通过同级交流轮换分工。
5. 若想直接看中央、省级玩法，点击“选择开局 → 分层体验”，指定岗位。这会替换当前存档，可先导出备份。
6. “推进一季度”最多推进三个月，考核、任职阶段变化或结局会中断；期间未处理事件仍可能逾期。

## 代码

- `engine.js`：无 DOM 的规则引擎，可在 Node 与浏览器复用。
- `career.js`：岗位图、考察状态机、分层地区台账与协同反馈。
- `career-ui.js`：任职、机构总览、地区治理和分层开局界面。
- `app.js`：界面、输入、自动存档及导入导出。
- `style.css`：地图、响应式界面、键盘焦点与减少动画适配。
- `test.cjs`、`career.test.cjs`、`map.test.cjs`、`civic.test.cjs`：57 项测试，执行 `npm test`，或分别运行 `node test.cjs` 和 `node career.test.cjs`。
- `journey.cjs`：用正常游戏命令自动经营，验证政府和党委路线的长期可达性。
- `研究与开发思路.md`：来源核验、机制拆解、实现模型与后续扩展。

## 验证

57 项自动测试覆盖财政建设、专项资金、人事、19 个岗位开局、任职程序、分管权限、反馈传导和存档迁移。整段经营测试不改写现金、声誉、分数、月份或岗位，验证两条路线均可在 420 个月内达到中央终点并结束生涯。浏览器已验证中央开局、提案扣款与反馈、机构总览及存档加载。


新增土地、民生、产业三个菜单。v1–v4 存档迁移到 v5 时初始化新台账，不改写旧城市与资金；地图仍可扩展。

人事改为行政、教育事业、医疗事业三本独立台账，增编需申报审核。新增行政中心办公扩建和政务服务站，设施不自动增编。旧档迁移保留人员与待到岗安排。
